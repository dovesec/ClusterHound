# CH_ExternalActor

## Overview

Synthetic node representing an unauthenticated external threat actor with network-level visibility of the API server or Kubelet API. Source of `CH_unauthAPIAccess` and `CH_unauthKubeletAccess` edges.

## Scope

Cluster

## Properties

| Property | Description |
|----------|-------------|
| name | Always "External Actor" |
| description | Human-readable description of the node's role |
